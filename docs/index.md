# ScreenHire docs

Read the lines below, open the folder or doc whose line answers the question, and stop there. Each folder index lists its docs the same way.

## Start here

* [ScreenHire documentation](README.md) - Where to start reading by audience (trying the demo, building a feature, changing UI, reviewing, planning), what ScreenHire is, who it is for and why it exists, and a pointer to index.md, the map of every concept.
* [MVP status](status.md) - What is built and in which PR, the acceptance journey that walks it end to end, the local stand-in for each external integration, every owner action (accounts, keys, legal reviews) needed before real use, and the known gaps.
* [Roadmap](roadmap.md) - The order of work after the MVP: what each finished workflow delivered and in which PRs, what comes next (candidate replies by email with an optional company sending domain, questionnaire sections with progress and save-and-resume, the embeddable careers widget, interview scheduling, adding candidates by hand with server search and reports, organization branding, a talent pool, rich text for job descriptions and email templates, connecting to Slack), later items, and what must exist before real customers.

* [Decisions](adr/index.md) - The architecture decision records and their status: the decision log.
